# Examples

Place tree dumps and golden files here for reference and testing.

## Tree Dumps

Use `OLPTranslators/Simple_Python_Translator.py` in E2 to generate a complete dump of the OLP object tree. This shows all programs, operations, motions, events with their attributes and types.

Place tree dumps in `tree_dumps/` with descriptive names:
```
examples/tree_dumps/<vendor>_<description>.txt
```

## Golden Files

Expected output files for comparison testing. Organized by vendor:
```
examples/golden_files/<VENDOR>/
```
