# FASTSUITE E2 — Community Plugins

Community-contributed OLP downloaders, uploaders, technology plugins, and examples for FASTSUITE E2.

This repository is used as a **git submodule** in the [fastsuite-copilot-starter](https://github.com/cenit-dfs/fastsuite-copilot-starter) template. VS Code Copilot references these files as working examples when helping you build new plugins.

## What This Repo Contains

**Reference code and examples only.** Everything here is general-purpose — no customer-specific logic, no large binary files, no E2 installation files.

### Reference Downloaders

| File | Maintained by | Description |
|------|---------------|-------------|
| `OLPTranslators/KUKA/KUKA_KRC5.py` | CENIT | **Canonical base downloader** — KUKA KRC5 with motion FOLDs, position data, multi-signal event handling |
| `OLPTranslators/ABB/ABB_IRC5.py` | CENIT | **Advanced multi-plugin** — ABB IRC5 with technology plugin architecture |
| `OLPTranslators/Simple_Python_Translator.py` | CENIT | **OLP tree dumper** — downloads the complete E2 object tree as `.txt` for analysis |

Community contributions add new vendors or controller variants alongside the canonical files:

```
OLPTranslators/
├── Simple_Python_Translator.py          ← diagnostic tool (CENIT)
├── KUKA/
│   ├── KUKA_KRC5.py                     ← canonical (CENIT)
│   └── KUKA_KRC4.py                     ← community contribution
├── ABB/
│   ├── ABB_IRC5.py                      ← canonical (CENIT)
│   └── ABB_IRC5_ArcWelding.py           ← community: welding variant
├── FANUC/
│   └── FANUC_R30iB.py                   ← community contribution
└── ...
```

### Examples

| Folder | Description |
|--------|-------------|
| `examples/tree_dumps/` | OLP object tree dumps generated by `Simple_Python_Translator.py` |
| `examples/golden_files/<VENDOR_CONTROLLER>/` | Expected downloader output (small text files) |

## What Does NOT Belong Here

| Content | Where it belongs |
|---------|-----------------|
| Customer-specific customizations | Your private repo (clone of the starter) |
| `.cendoc` scenario files | Your private repo in `tests/scenarios/` (Git LFS) |
| Customer-specific golden files | Your private repo in `tests/golden/` |
| Skills, agent files, Copilot instructions | [fastsuite-copilot-starter](https://github.com/cenit-dfs/fastsuite-copilot-starter) only |
| E2 installation files | Never in any repo |

## How to Use

This repo is typically consumed as a submodule:

```bash
# From your fastsuite-copilot-starter project:
git submodule update --init
```

Update to the latest community code:

```bash
cd community
git pull origin master
cd ..
git add community
git commit -m "Update community reference code"
```

You can also browse the code directly on GitHub for reference.
