# PRIMA OLP Translators

## PRIMA_XML_ul.py
PRIMA laser cutting **uploader** — imports PRIMA XML format programs back into E2.

> **Note:** This uploader requires `numpy` which must be available in the Python environment.
> Standard E2 Python may not include `numpy` — check your installation before use.

## Related
- LaserCuttingTechnology — see `community/Technologies/LaserCuttingTechnology/PRIMA/`
- Legacy `.pp` translators (PRIMA_ISO, PRIMA_P20L_P30L, PRIMA_RMLPLUS, PRIMA_XML) are not Python-based and not included here.
