# DAIHEN (OTC) OLP Translators

## Daihen_FD19.py
Base DAIHEN FD19 controller downloader.

## Daihen_FD19_Arc_Welding.py
DAIHEN arc welding plugin — extends the base downloader with arc welding technology events.

## Daihen_FD19_Arc_Classes.py
Shared data classes used by both the base and arc welding downloaders.

## Daihen_FD19_ul.py
DAIHEN FD19 **uploader** — imports DAIHEN robot programs back into E2.

## Dependencies
- ArcWeldingTechnology — see `community/Technologies/ArcWeldingTechnology/DAIHEN/`
